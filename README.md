# Kishan Lakhani Portfolio

Static portfolio site for Kishan Lakhani, built with HTML, CSS, and vanilla JavaScript.

## Free deployment with GitHub Pages

1. Upload the files in this folder to the `kishanpatel11999/portfolio` repository.
2. In GitHub, open **Settings -> Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
4. Add `kishanlakhani.in` as the custom domain if GitHub does not pick up the included `CNAME` file.
5. At your domain provider, point the root domain to GitHub Pages with the four A records listed in GitHub Pages settings. Point `www` to `kishanpatel11999.github.io` with a CNAME record.
6. Enable HTTPS in GitHub Pages after DNS finishes propagating.

The site has no build step or paid dependency, so GitHub Pages can serve it directly from the repository root.
